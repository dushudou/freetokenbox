Scope: public first-party pages checked on this date; no account creation or generation test. Web/app allowances do not imply API credits. Unknown fields below must remain unknown in listings. Credits are vendor units, not LLM tokens or a fixed number of assets.

## Qualified or conditional candidates

- **Hyper3D / Rodin:** Current pricing confirms free generation/preview before confirmation, legacy-model exports and 10 private assets. Help documentation says Rodin Gen-1.5/Gen-2.5 at Medium or below can be previewed free, but credits are deducted on confirmation; High/Extreme High charge during generation. Homepage/image-to-3D pages mention free starting credits but do not quantify them. Suitable only as “free preview / introductory credits, amount not disclosed,” never “unlimited free export.” Commercial license is listed as a paid feature. Sources: [pricing](https://hyper3d.ai/pricing?lang=en), [credit charging guide](https://hyper3d.ai/de/help/articles/how-many-credits-does-each-hyper3d-generation-cost), [image-to-3D feature page](https://hyper3d.ai/features/image-to-3d), [API pricing](https://hyper3d.ai/features/api).

- **Tencent Hunyuan 3D API:** Global launch announcement offered enterprise API users 200 free credits. However, current mainland [TokenHub product page](https://cloud.tencent.com/product/tokenhub) advertises **100 credits for HY-3D-3.1 new users**. These are different channels/eligibility, so never merge into a single generic “Tencent API 200 free credits” offer. Mainland [Hunyuan 3D billing overview](https://cloud.tencent.com/document/product/1804/123461) does not currently expose a clear matching free grant in fetched text. Prefer listing the clearly scoped Global web offer first; API expiry and eligibility need another check.

## Exclude from verified free AI-generation list

- **Spline AI:** Free editor exists, but current pricing explicitly includes **no AI credits**. AI 3D Generation documentation calls it a paid feature. Free MCP tool calls and a free 3D editor do not establish free AI asset generation. Sources: [pricing](https://spline.design/pricing), [AI 3D documentation](https://docs.spline.design/generate/ai-3d-generation).
- **Pika:** Canonical pricing and FAQ now say Free has **0 monthly credits / packs only**. Free means an account can purchase packs without a subscription. Older indexed official URLs still claim 80 or 150 credits/month and conflict with current pages; do not publish these obsolete quotas. Pricing says no watermark while an academy page says watermarked Free output, another unresolved inconsistency. Sources: [current pricing](https://pika.art/pricing?interval=month), [current FAQ](https://pika.art/faq), [academy page showing conflicting restrictions](https://pika.art/learn/consistent-character-ai-videos). A possible account-specific grant is not a documented universal free allowance.
- **Kling:** Official klingai.com domain blocks the browsing tool via robots.txt. No reliable primary-source free allowance was obtained. Keep unverified rather than copy third-party “66 daily credits” claims. This research does not establish that Kling lacks free access.
- **Hunyuan local open weights:** Not a hosted free quota; compute must be supplied. Licenses vary by repository/model version and must be checked individually. Do not transfer a local-model license to the hosted web product. Example primary sources: [Hunyuan3D-2 license](https://github.com/Tencent-Hunyuan/Hunyuan3D-2/blob/main/LICENSE), [Hunyuan3D-2.1 repository](https://github.com/Tencent-Hunyuan/Hunyuan3D-2.1).

## Editorial recommendation

Publish Meshy, Tripo Studio, Runway and Hunyuan Global as the clearest quantified web offers. Tripo API can be a separate introductory-credit entry, with its two-week wording carefully qualified. Luma and Hailuo are useful additions with **unquantified** free access and explicit caveats. Hyper3D belongs under free previews. None should be advertised as unlimited, unrestricted commercial asset generation, or free API access unless the relevant source explicitly says so.
