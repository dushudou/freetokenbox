# FreeTokenBox 视觉设计决策记录

> 方法：`design-an-interface`（Design It Twice）——并行产出 3 个风格迥异的方案，对比后合成。

## 三个候选方向

| 方向 | 气质 | 配色 | 要点 |
|---|---|---|---|
| **A 编辑/杂志风** | 印刷感、可信 | 纸色 #F7F4EE + 朱砂红 #C2431F | 衬线标题（Newsreader/思源宋体）、发丝线系统、首字下沉、眉题 kicker |
| **B 现代极简/Apple** | 静奢、高级 | 浅灰 #F5F5F7 + 翡翠绿 #0C8F62 | 大留白、1px 发丝线、大圆角、克制阴影、磨砂吸顶、等宽数字 |
| **C 高密度工具/ProductHunt** | 扫读快、实用 | 冷锌 + 靛蓝 #5B4DF1 | 排名序号、到期时钟、计数条、状态徽章 |

完整方向 A 规范见 `docs/design-direction-a-editorial.md`。

## 合成结论（已落地）

FreeTokenBox 是「免费额度目录」，首要任务是**可扫读 + 可信 + 高级感**。最终采用：

- **骨架 = B 现代极简**：浅灰画布、发丝线 + 大圆角 + 克制阴影、磨砂吸顶导航、系统字体栈（零加载成本，CJK 原生渲染）、等宽数字（tabular-nums）。
- **数据密度 = C 的信号**：条目「免费」徽章 + 到期状态徽章（≤7 天警告 / 已截止红色）、侧边栏「热门精选」排名序号（前三高亮）、分类计数徽章。
- **编辑点缀 = A 的眉题**：首页 banner 顶部 mono kicker（"CURATED · FREE AI TOKENS"）+ 大标题紧字距 + 数据条，赋予差异化品味。

强调色用**翡翠绿**（绿色天然传达"免费/有效"语义），一色三档，不铺色块。

## 约束（保持不变）

- 无 emoji（全部内联 SVG + `currentColor`）
- 单一 `<h1>`、语义化结构，SEO / Agent / LLM 友好不退化
- AdSense 占位 `<div class="ad-slot">` 保留，接入时不改结构
- 明暗自适应（`prefers-color-scheme`），移动端单列、侧栏移入主栏之后
- 背景不做大面积渐变、不发光
